# Akila Sandaruwan - Professional Portfolio

A responsive personal portfolio created for the System Analysis and Design assignment. It presents my profile, education, technical and professional skills, selected projects, work experience, CV and contact information.

## Live portfolio

After GitHub Pages is enabled for the `main` branch, the portfolio will be available at:

`https://akila20030110-glitch.github.io/professional-portfolio/`

## Portfolio sections

- Home and professional introduction
- About and career objective
- Education and relevant studies
- Technical, design and soft skills
- Three project cards with verified links where available
- Work experience and university activities
- Viewable and downloadable CV
- Email and GitHub contact links

## Featured projects

1. [ASL Sign Language to Text](https://github.com/akila20030110-glitch/asl-sign-language-to-text)
2. [UniFind](https://github.com/akila20030110-glitch/UniFind)
3. A reserved project card awaiting verified details and an original screenshot

The portfolio intentionally uses clear placeholders where original project images or verified third-project details are not yet available. This avoids presenting generated or unrelated images as real project evidence.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Run locally

No installation or build step is required. Clone the repository and open `index.html` in a modern web browser.

```bash
git clone https://github.com/akila20030110-glitch/professional-portfolio.git
cd professional-portfolio
```

## Responsive and accessible design

The site includes a keyboard-accessible mobile menu, visible focus styles, semantic page structure, a skip link, responsive layouts, reduced-motion support and external-link safety attributes.

## Updating project images

When original screenshots become available, add them under `images/projects/` and replace the matching `.project-placeholder` element in `index.html` with an image such as:

```html
<img class="project-image" src="images/projects/project1.jpg" alt="ASL Sign Language to Text application interface">
```

Only screenshots from the actual projects should be used.
